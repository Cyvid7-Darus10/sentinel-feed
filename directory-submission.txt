DESCRIPTION & TAGS
------------------

Description:
Checking Hacker News, GitHub Trending, Lobsters, Dev.to, daily.dev, Techmeme,
and InfoQ every morning means seven tabs and a lot of the same links twice.

Sentinel Feed pulls all seven on a 15-minute cron, drops duplicate URLs, sorts
each story into a topic, ranks by score, and puts the result behind one
dashboard.

There are three ways to read it. Radar plots every story as a dot inside a
topic sector, where score pulls the dot toward the center and makes it bigger,
and security stories pulse red. Map shows all six sectors at once with the top
stories in each. List is a plain ranked feed with topic tabs, for skimming.

The six sectors are Security, AI/ML, Systems, Dev, Tools, and General, assigned
by keyword and tag matching. Separately, anything matching a CVE, zero-day,
breach, or exploit pattern gets flagged as critical, so it does not get buried
under trending repos.

Filtering is by source, by time window (6h, 12h, 24h, 7d), or by typing, which
searches titles, summaries, authors, and tags. With an API key configured, each
story also gets a one-line summary from Claude Haiku.

None of the sources need an API key. They are fetched in parallel with
independent error handling, so a source going down costs you that source and
nothing else. Works on a phone.
